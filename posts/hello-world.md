## how to write a new post

1. create a markdown file in `posts/`, e.g. `posts/my-post.md`.
2. add an entry to `posts/manifest.json` with the slug, title, date, and optional tags + excerpt.
3. commit and push. it shows up on the blog index automatically.

thats it. no build step. just markdown and a json file.
